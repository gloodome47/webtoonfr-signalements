# WebtoonFR — signalements de sites

Ce dépôt sert **uniquement** à recevoir les signalements « ce site ne marche pas » envoyés depuis l'app WebtoonFR
(Réglages → 🚩 Signaler un site, ou 🚩 sur la page d'une œuvre / dans le lecteur).

L'app ouvre un ticket déjà rempli : il suffit de toucher **Create**. Seuls l'adresse du site, le problème choisi
et la version de l'app sont envoyés.

Les sites signalés sont corrigés dans les mises à jour suivantes, puis le ticket est fermé.
